# customer_behavior_analysis

## Overview

This project focuses on analyzing customer behavior using Python, PostgreSQL, and Power BI.
The workflow includes data loading, data cleaning, exploratory data analysis (EDA), SQL-based analysis, and dashboard creation to generate actionable business insights.

The goal of this project is to demonstrate end-to-end data analytics skills commonly used in real-world business environments.

## Dataset

The dataset contains customer-related information such as:

* Customer demographics
* Purchase behavior
* Spending patterns
* Product preferences
* Transaction details

The data was processed and analyzed to identify trends, customer segments, and business opportunities.

## Project Workflow

### 1. Data Loading

* Imported dataset into Python using Pandas
* Connected Python with PostgreSQL using SQLAlchemy
* Loaded cleaned data into PostgreSQL tables

### 2. Data Cleaning

* Removed duplicates
* Handled missing values
* Fixed inconsistent data types
* Standardized column names

### 3. Exploratory Data Analysis (EDA)

Performed analysis to understand:

* Customer purchasing behavior
* Revenue trends
* Product performance
* Customer segmentation
* Correlation between variables

### 4. SQL Analysis using PostgreSQL

Executed SQL queries for:

* Top customers analysis
* Revenue calculations
* Product category insights
* Monthly sales trends
* Customer segmentation analysis

### 5. Power BI Dashboard

Created an interactive dashboard to visualize:

* Sales performance
* Customer insights
* Revenue trends
* KPIs and metrics
* Product category analysis

## How to Run the Project

### 1. Clone the Repository

```bash
git clone <repository_link>
cd <project_folder>
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Configure PostgreSQL Connection

Create a `.env` file:

```env
DB_USER=your_username
DB_PASSWORD=your_password
DB_HOST=localhost
DB_PORT=5432
DB_NAME=your_database
```

### 4. Run Python Scripts

```bash
python main.py
```

### 5. Open Power BI Dashboard

Open the `.pbix` file in Power BI Desktop.
